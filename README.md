# 경성의 고독한 미식가들 — 관객 동선 워크플로우

이머시브 공연 《경성의 고독한 미식가들》의 관객 60명 동선을 단계별로 진행하는 인터랙티브 시각화입니다.

## 사용법

- **화면 클릭** 또는 `다음 ▸` 버튼 — 다음 단계 진행 (인솔자별 칩이 공간 사이를 이동)
- **1막 / 2막 탭** — 막 전환 (키보드 `1`, `2`)
- 키보드 `←` `→` `Space` — 이전/다음
- 상단 점 클릭 — 해당 단계로 점프
- 각 공간 박스에 진행 중인 씬 번호·제목과 관객 수 표시, 하단에 검산식
- 마지막 단계 — 블록별 검증 요약 + 리스크

## 데이터 기준

- 2막 인원·라우팅: 씬 브레이크다운 0710 (확정)
- 1막 인원: 0615 대본 기준 + 부분 추정 (0710은 1막 인원 미기재)
- 런닝타임: 미실측 (리허설 확정 대기)

⚠️ 작품 내용(사건·결말)이 포함된 제작진 공유용 자료입니다.
